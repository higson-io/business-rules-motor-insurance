## Documentation Language & Upkeep

### Project Documentation Is Written in Polish
Project-level documentation under `.maister/docs/project/` (tech stack, architecture) is written in Polish — the team language preference. Keep new project docs in the same language. Coding standards under `.maister/docs/standards/` and `INDEX.md` are in English, matching the language of the code and its comments.

*Evidence:* CLAUDE.md and INDEX.md both record the Polish preference for project docs.

### Keep the Docs Index in Sync
Update `.maister/docs/INDEX.md` whenever documentation is added, removed or significantly changed. Update project documentation when goals, tech stack or architecture change; update standards when team conventions evolve.

*Evidence:* INDEX.md maintenance section.
